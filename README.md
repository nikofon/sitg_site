# SITG — веб-сайт

[English](README.en.md)

Веб-интерфейс SITG для игроков, авторов и организаторов турниров.

## Возможности

- Поиск игроков, рейтинги, статистика и результаты игр.
- Просмотр турниров, регистрация, расписание и турнирные таблицы.
- Каталог авторов и статистика их вопросов.
- Библиотека пакетов вопросов и чтение доступных материалов.
- Управление турнирами, участниками, пакетами, этапами и абонементами.
- Администрирование турниров, игроков и авторов.

Сайт поддерживает русский и английский языки. Публичные страницы игроков и турниров
доступны без входа; личные действия требуют входа через Telegram и соответствующих прав.
Сами игры, завершение регистрации аккаунта и получение DOCX-файлов проходят в Telegram.
